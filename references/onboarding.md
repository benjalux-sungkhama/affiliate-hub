# การสมัครและเข้าสู่ระบบ

## สมัครครั้งแรก
1. ขอ **รหัสเข้าใช้งาน (Access Code)** จากแอดมิน
2. เปิดหน้าเว็บระบบ กด **"สมัครด้วยรหัสเข้าใช้งาน"**
3. กรอก: รหัสเข้าใช้งาน, ชื่อ, อีเมล, รหัสผ่าน (2 ครั้ง) แล้วกดสมัคร

## เข้าสู่ระบบ
- ใช้ **อีเมล + รหัสผ่าน** ที่สมัครไว้
- ติ๊ก "จดจำฉันไว้" เฉพาะเครื่องส่วนตัว
- ลืมรหัสผ่าน → กด "ลืมรหัสผ่าน?" (ต้องตั้งค่าอีเมลในระบบไว้ก่อน)

## จัดการ Access Code (แอดมิน)
ไปที่ **ตั้งค่า → รหัสเข้าใช้งาน**
- สร้างรหัสใหม่: ระบุป้ายกำกับ, จำนวนครั้งที่ใช้ได้, วันหมดอายุ
- ตารางตรวจสอบสถานะการใช้งาน
- เปิด/ปิด หรือลบรหัสได้ตลอดเวลา

## ข้อควรรู้
- ข้อมูลผู้ใช้แต่ละคนแยกกัน 100% เหมาะกับทีมหลายคนในระบบเดียว
- รหัสหมดอายุหรือใช้ครบจำนวนแล้วจะสมัครไม่ได้ ต้องขอรหัสใหม่
