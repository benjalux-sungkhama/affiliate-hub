# การตลาด — AffiliateHub

ครอบคลุมโมดูลแพลตฟอร์ม, ตารางโพสต์, AI คิดคอนเทนต์, คลังสูตร, คิวโพสต์, วิเคราะห์ & Boost และไลฟ์สด

---

## §1 เชื่อมต่อบัญชี (โมดูลแพลตฟอร์ม)

**เมนู:** แพลตฟอร์ม → เลือก Facebook / TikTok / Shopee / Lazada → แท็บ **บัญชีที่เชื่อม**

1. กด **+ เชื่อมบัญชีใหม่**
2. เลือกประเภท: เพจ / ร้านค้า / โปรไฟล์
3. กรอกชื่อที่ใช้แสดง + Token หรือ API Key ของแพลตฟอร์มนั้น
4. กด **ทดสอบการเชื่อมต่อ** → ต้องขึ้น ✅ ก่อนบันทึก

| สถานะ | ความหมาย | ต้องทำอะไร |
|---|---|---|
| เชื่อมต่อแล้ว | ใช้งานได้ปกติ | — |
| Token หมดอายุ | ต่ออายุไม่สำเร็จ | กด **เชื่อมใหม่** |
| ถูกปฏิเสธสิทธิ์ | ขาด permission | ตรวจสิทธิ์แอดมินเพจ |
| ยังไม่เชื่อม | ยังไม่ผูกบัญชี | กด **+ เชื่อมบัญชีใหม่** |

> บัญชีที่เชื่อมผูกกับ `user_id` ของคุณเท่านั้น คนอื่นมองไม่เห็น

## §2 ตั้งค่าการโพสต์ & ช่วงเวลา

**เมนู:** แพลตฟอร์ม → **ตั้งค่าการโพสต์ & ช่วงเวลา**

- **โซนเวลา:** Asia/Bangkok (ค่าเริ่มต้น)
- **ช่วงเวลาแนะนำ:** ระบบดึงจากสถิติไลฟ์ + โพสต์ย้อนหลัง 30 วัน
- **จำนวนโพสต์สูงสุด/วัน:** ตั้งต่อแพลตฟอร์มได้แยกกัน
- **เว้นระยะขั้นต่ำ:** กันโพสต์ถี่เกินจนโดนลดการมองเห็น (แนะนำ ≥ 90 นาที)

**สล็อตมาตรฐาน (แก้ไขได้):**

| ช่วง | เวลา | เหมาะกับ |
|---|---|---|
| เช้า | 07:00–09:00 | คอนเทนต์ให้ความรู้ |
| กลางวัน | 11:30–13:00 | โปรโมชัน / แฟลชเซล |
| เย็น | 17:00–19:00 | วิดีโอสั้น / รีวิว |
| ค่ำ | 20:00–22:30 | ไลฟ์ + CTA ปิดการขาย |

## §3 ให้ AI คิดคอนเทนต์ (บทที่ 10)

**เมนู:** แพลตฟอร์ม → **ให้ AI คิดคอนเทนต์**

หน้านี้สร้างได้ 3 อย่าง: **แคปชั่น**, **Prompt รูปภาพ**, **Prompt วิดีโอ (Storyboard)**
และมีแท็บ **คลังสูตรของฉัน** สำหรับเก็บสูตรไว้ใช้ซ้ำ (§3.3)

### §3.1 สูตร Storyboard มินิมอล 10 วินาที

โครงมาตรฐาน **6 ซีน × 1.5–2 วินาที** ใช้กับ Reels / TikTok / Shorts

| ซีน | เวลา | เนื้อหา | เป้าหมาย |
|---|---|---|---|
| 1 | 0.0–1.7 | เปิดตัวสินค้า วางบนพื้นสะอาด | หยุดนิ้ว |
| 2 | 1.7–3.4 | มือหยิบจับ / กล้องเข้าใกล้ | สร้างความอยากจับ |
| 3 | 3.4–5.1 | สาธิตการใช้งาน + Click ASMR | โชว์ฟังก์ชัน |
| 4 | 5.1–6.8 | ผลลัพธ์ before / after | พิสูจน์ค่า |
| 5 | 6.8–8.5 | มุมไลฟ์สไตล์ ใช้จริงในชีวิต | ให้เห็นภาพตัวเอง |
| 6 | 8.5–10.0 | CTA + โลโก้ + ราคา | ปิดการขาย |

**ทุก Prompt ต้องมีครบ 6 ส่วน:**
1. **ข้อมูลสินค้า** — ชื่อ, วัสดุ, สี, ขนาด, ราคา
2. **แนวคิดหลัก** — อารมณ์และสไตล์ภาพรวม
3. **ตัวละคร** — ใคร, อายุ, การแต่งตัว, มือ/หน้า
4. **Storyboard** — 6 ซีนพร้อมมุมกล้องและการเคลื่อนไหว
5. **Text Overlay** — ข้อความบนจอแต่ละซีน (สั้น ≤ 6 คำ)
6. **เสียง** — ดนตรี, SFX, เสียงพากย์

**กฎการเขียน:**
- ระบุมุมกล้องทุกซีน (close-up, top-down, 45°, tracking)
- ระบุแสง (soft daylight / studio / golden hour)
- ห้ามใส่ข้อความยาวบนจอเกิน 2 บรรทัด
- ซีน 6 ต้องมีราคาและคำสั่ง (สั่งเลย / ทักแชท / กดตะกร้า)

### §3.2 ตัวอย่าง Prompt พร้อมใช้ (Omni Flash)

```

ชาร์จ USB-C สว่าง 1200 lumens กันน้ำ IPX6

[แนวคิดหลัก]
มินิมอล พรีเมียม โทนเทา-ดำ แสง studio นุ่ม เน้นพื้นผิวโลหะ

[ตัวละคร]
มือผู้ชายวัย 30 ต้น ผิวสองสี เล็บสั้นสะอาด ข้อมือใส่นาฬิกาสายหนังดำ
เห็นเฉพาะมือและแขนท่อนล่าง ไม่เห็นใบหน้า

[Storyboard 6 ซีน × 1.7 วิ]
ซีน 1 (0.0–1.7) — top-down, ไฟฉายวางกลางพื้นคอนกรีตเรียบ แสง soft
  จากด้านซ้าย กล้องค่อย ๆ ซูมเข้า 5%

  แสงวิ่งไปตามขอบโลหะ

  ฝุ่นลอยในลำแสง (Click ASMR)

  ทั้งห้องด้วยไฟฉาย
ซีน 5 (6.8–8.5) — tracking shot กลางแจ้งตอนค่ำ มือถือไฟฉายส่องทาง

ไม่มีเสียงพากย์
```

### §3.3 คลังสูตรของฉัน (บันทึก / เพิ่มสูตรใหม่)

**เมนู:** ให้ AI คิดคอนเทนต์ → แท็บ **คลังสูตรของฉัน**

ใช้เก็บสูตรคอนเทนต์ของคุณเอง เพื่อเรียกใช้ซ้ำได้โดยไม่ต้องพิมพ์โครงใหม่ทุกครั้ง
สูตรทั้งหมดผูกกับ `user_id` — ของใครของมัน

#### วิธีบันทึกสูตรใหม่ (3 ทาง)

| วิธี | ทำอย่างไร | เหมาะกับ |
|---|---|---|
| **A. บันทึกจากผลลัพธ์** | สร้าง Prompt เสร็จ → กด **💾 บันทึกเป็นสูตร** → ตั้งชื่อ → บันทึก | สูตรที่เพิ่งเวิร์ค อยากเก็บไว้ |
| **B. สร้างจากศูนย์** | แท็บคลังสูตร → **+ สูตรใหม่** → กรอกฟอร์ม | ออกแบบสูตรเอง |
| **C. ก๊อปแล้วแก้** | เปิดสูตรเดิม → **ทำสำเนา** → แก้ → บันทึก | ต่อยอดจากสูตรเดิม |

#### ฟิลด์ในฟอร์มสร้างสูตร

| ฟิลด์ | บังคับ | ตัวอย่าง |
|---|---|---|
| ชื่อสูตร | ✅ | `วิดีโอสั้น 10 วิ — สายมินิมอล` |
| หมวด | ✅ | วิดีโอสั้น / แคปชั่น / รูปภาพ / ไลฟ์ |
| แพลตฟอร์มที่เหมาะ | — | TikTok, Reels |
| ความยาวรวม (วิ) | — | `10` |
| จำนวนซีน | — | `6` |
| โครงซีน (เพิ่มได้ไม่จำกัด) | ✅ (ถ้าเป็นวิดีโอ) | ดูตารางย่อยข้างล่าง |
| สไตล์ Text Overlay | — | ≤ 6 คำ ฟอนต์หนา ขาว |
| แนวเสียง | — | lo-fi 90 BPM + SFX |
| โทนภาษา | — | สุภาพ กระชับ ไม่ขายตรง |
| ตัวแปรที่ใช้ | — | `{{product_name}}`, `{{price}}` |
| หมายเหตุ | — | ใช้กับของชิ้นเล็กได้ดี |

**โครงซีนต่อ 1 แถว:** ลำดับ, ช่วงเวลา, เนื้อหา, มุมกล้อง, แสง, ข้อความบนจอ

#### ระบบตัวแปร (Placeholder)

ใส่ตัวแปรในสูตร แล้ว AI จะเติมค่าให้อัตโนมัติตอนเรียกใช้

| ตัวแปร | ดึงมาจาก |
|---|---|
| `{{product_name}}` | เมนูสินค้า |
| `{{price}}` | เมนูสินค้า → ราคาขาย |
| `{{usp}}` | ช่องจุดขายที่กรอกตอนเรียกใช้ |
| `{{target}}` | กลุ่มเป้าหมายที่กรอกตอนเรียกใช้ |
| `{{cta}}` | ค่าเริ่มต้นจากตั้งค่า หรือพิมพ์ทับได้ |
| `{{platform}}` | แพลตฟอร์มที่กำลังสร้างโพสต์ |

> ตัวแปรที่หาค่าไม่เจอ ระบบจะ **ถามผู้ใช้ก่อนสร้าง** ไม่ปล่อยเป็นช่องว่าง

#### การเรียกใช้สูตร

1. หน้า **ให้ AI คิดคอนเทนต์** → ช่อง **เลือกสูตร** (ค่าเริ่มต้น = สูตรที่ตั้ง Default ไว้)
2. เลือกสินค้า → กรอกจุดขาย + กลุ่มเป้าหมาย
3. กด **สร้างคอนเทนต์** → ระบบเติมตัวแปรลงโครงสูตรแล้วส่งให้ AI
4. กด **ส่งเข้าคิวโพสต์** หรือ **💾 บันทึกเป็นสูตรใหม่** ถ้าแก้จนได้เวอร์ชันที่ดีกว่า

#### จัดการสูตร

- **ตั้งเป็นค่าเริ่มต้น** — สูตรที่จะถูกเลือกอัตโนมัติในหมวดนั้น (หมวดละ 1 สูตร)
- **เวอร์ชัน** — ทุกครั้งที่แก้แล้วบันทึก ระบบเก็บเวอร์ชันเดิมไว้ ย้อนกลับได้
- **เปิด/ปิดใช้งาน** — ปิดแล้วยังอยู่ในคลัง แต่ไม่ขึ้นในตัวเลือก
- **นำเข้า/ส่งออก JSON** — แชร์สูตรให้ทีมหรือย้ายเครื่อง
- **ลบ** — ต้องยืนยัน 2 ชั้น (สูตรที่ถูกใช้ในโพสต์ที่ยังเข้าคิวอยู่ ลบไม่ได้)

#### สถิติสูตร (บอกว่าสูตรไหนเวิร์ค)

ตารางในแท็บคลังสูตรแสดงต่อสูตร:

| คอลัมน์ | ความหมาย |
|---|---|
| ใช้ไปแล้ว | จำนวนครั้งที่สร้างคอนเทนต์จากสูตรนี้ |
| โพสต์ที่เผยแพร่ | นับเฉพาะที่ขึ้นจริง |
| Reach เฉลี่ย | ค่าเฉลี่ยต่อโพสต์ |
| CTR เฉลี่ย | ค่าเฉลี่ยต่อโพสต์ |
| ยอดขายที่ผูก | รวมจากออเดอร์ที่ผูกที่มาเป็นโพสต์นั้น |
| ใช้ล่าสุด | วันที่ |

เรียงตาม CTR หรือยอดขายได้ เพื่อดูว่าสูตรไหนควรใช้ต่อ

### §3.4 กติกาการเลือกสูตร (สำหรับ AI)

เมื่อผู้ใช้ขอคอนเทนต์ ให้ทำตามลำดับนี้:

1. ถ้าผู้ใช้ระบุชื่อสูตร → ใช้สูตรนั้น
2. ถ้าไม่ระบุ → ดูว่ามีสูตร **Default** ในหมวดที่ตรงกันไหม → ใช้สูตรนั้น
3. ถ้าคลังว่าง → ใช้สูตรมาตรฐาน §3.1
4. ถามข้อมูลที่ขาดก่อนเสมอ: **ชื่อสินค้า, จุดขาย, กลุ่มเป้าหมาย**
5. ส่งผลลัพธ์ที่เติมครบทุกช่อง — **ห้ามส่งโครงเปล่าให้ผู้ใช้กรอกเอง**
6. ปิดท้ายด้วยการถามว่าจะ **บันทึกเป็นสูตรใหม่** ไหม

## §4 สร้าง จัดคิว และจัดการโพสต์

**เมนู:** แพลตฟอร์ม → **สร้าง จัดคิว และจัดการโพสต์**

| สถานะ | ความหมาย |
|---|---|
| ฉบับร่าง | บันทึกไว้ ยังไม่ตั้งเวลา |
| เข้าคิว | ตั้งเวลาแล้ว รอเผยแพร่ |
| เผยแพร่แล้ว | ขึ้นจริงบนแพลตฟอร์ม |
| ล้มเหลว | ส่งไม่สำเร็จ (ดูเหตุผลในคอลัมน์ Log) |

- ลากเปลี่ยนเวลาในมุมมองปฏิทินได้
- โพสต์ที่ล้มเหลว กด **ลองใหม่** ได้ 3 ครั้ง
- ผูก **สินค้า** กับโพสต์ไว้ เพื่อให้ระบบเชื่อมยอดขายกลับมาได้
- โพสต์ที่สร้างจากสูตรจะเก็บ `formula_id` ไว้ เพื่อคำนวณสถิติสูตรย้อนกลับ

## §5 วิเคราะห์ & AI แนะนำ Boost

**เมนู:** แพลตฟอร์ม → **วิเคราะห์ & AI แนะนำ Boost**

**ตัวชี้วัดหลัก:** Reach, Engagement, CTR, ยอดขายที่ผูกกับโพสต์, ต้นทุนต่อคลิก

**เกณฑ์ที่ AI ใช้แนะนำ Boost:**

| เงื่อนไข | คำแนะนำ |
|---|---|
| CTR > ค่าเฉลี่ย 30 วัน × 1.5 | แนะนำ Boost ทันที |
| Engagement สูงแต่ CTR ต่ำ | แก้ CTA ก่อนค่อย Boost |
| Reach ต่ำใน 2 ชม.แรก | เปลี่ยนช่วงเวลาโพสต์ |
| มียอดขายผูก ≥ 3 ออเดอร์ | Boost ด้วยงบสูงขึ้น |

> ถ้าโพสต์ที่ผลดีมาจากสูตรเดียวกันซ้ำ ๆ ให้แนะนำผู้ใช้ตั้งสูตรนั้นเป็นค่าเริ่มต้น

## §6 ไลฟ์สด

**เมนู:** การจัดการ → **ไลฟ์สด**

1. กด **+ เริ่มรอบไลฟ์** → ตั้งชื่อรอบ + เลือกแพลตฟอร์ม
2. ระหว่างไลฟ์ บันทึก: ผู้ชมสูงสุด, คอมเมนต์, ออเดอร์, สินค้าที่ขายได้
3. จบไลฟ์ กด **ปิดรอบ** → ระบบสรุปให้อัตโนมัติ

**รายงานที่ได้:** กราฟผู้ชมตามเวลา, ช่วงนาทีที่ขายดีที่สุด, สินค้าที่ปังสุด, ยอดขายรวม/รอบ

## ภาคผนวก A — Schema & Prompt สร้างฟีเจอร์คลังสูตร

ใช้ตอนติดตั้ง (อยู่ในรูป Prompt 4.4b ของ `references/installation.md`)

### ตารางที่ต้องมี

```sql
-- สูตรหลัก
content_formulas (
  id, user_id, name, category, platforms, total_seconds,
  scene_count, overlay_style, audio_style, tone, notes,
  variables_json, is_default, is_active, version,
  parent_id, created_at, updated_at
)

-- ซีนในสูตร
content_formula_scenes (
  id, formula_id, seq, time_from, time_to, description,
  camera_angle, lighting, overlay_text
)

-- สถิติการใช้งาน
content_formula_usages (
  id, formula_id, user_id, post_id, product_id,
  reach, engagement, ctr, linked_sales, used_at
)
```

**Index ที่จำเป็น:** `(user_id, category)`, `(formula_id, seq)`, `(formula_id, used_at)`

### รูปแบบ JSON สำหรับนำเข้า/ส่งออก

```json
{
  "name": "วิดีโอสั้น 10 วิ — 6 ซีนมาตรฐาน",
  "category": "วิดีโอสั้น",

  "total_seconds": 10,
```
